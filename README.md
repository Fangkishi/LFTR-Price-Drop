# LFTR: Price Drop

一个可选模组。它不改 GT++ 的源码，只在加载结束时重排 GT++ **LFTR（液态氟钍反应堆）** 产线上的一批配方：造价从单点合金换成主线材料、燃料线多一条不用工业氢氟酸的通路、燃料与乏燃料处理更快。

> ⚠️ **不符合星门（Stargate）规则。** 星门身份要求在不改平衡的前提下达成，而本模组有意改动造价与处理速度。跑星门、或准备申请星门身份时不要安装。
>
> 与 GTNH 官方、GT++、GT5U 均无隶属关系。jar 里不含上游的任何代码或资源，只在运行期调用它们的配方 API。

**English:** [README.en.md](README.en.md)

## 装法

- GTNH 1.7.10，Forge 10.13.4.1614
- 需要 GT5-Unofficial 5.09.54.265（GT++ 以 `miscutils` 的身份内置在 GT5U 里，**不要**再去单独找 GT++ 的 jar）
- 把 `lftrpricedrop-<版本>.jar` 放进 `mods/`，启动一次即可
- 每次加载都会打印 `[LFTR]` 日志：36 条逐条命中，3 行分组汇总

### B 组 · 氢氟酸通路，6 条

3 条新增、3 条替换。换算沿用 GT++ 既有的比例：**1 mB 工业氢氟酸 = 2 mB 普通氢氟酸**。

| 配方 | 操作 | 变化 |
|---|---|---|
| 碳酸锂 → 氟化锂（化学浸洗机） | 新增 | 工业氢氟酸 500 → 普通氢氟酸 1000 |
| 氢氧化锂 → 氟化锂（化学反应釜 + 大型化学反应釜） | 新增 | 工业 500 → 普通 1000 |
| U-233 + U-235 → 四氟化铀（混合机） | 新增 | 工业 10000 → 普通 20000 |
| 四氟铍酸铵 → 氟化铍（大型化学反应釜） | 替换 | 副产工业 1000 → 普通 2000 |
| 燃料基（工业高炉） | 替换 | 输入 +2 空单元；副产 2 个工业氢氟酸单元 → 4 个普通氢氟酸单元 |
| 燃料基（化工厂） | 替换 | 副产工业 2000 → 普通 4000 |

脱水机制氟化铍那条不改，它继续副产 1 个工业氢氟酸单元。

## 配置

`config/lftrpricedrop.cfg`：

```
B:enablePriceDrop=true
```

改成 `false` 就一条配方都不碰，日志里只会出现一行「配置关闭」。

## 为什么有的改动是新增、有的是替换

GT 匹配配方时**只看输入**、允许机器里有多余输入、并且取第一条匹配。所以：

- **输入不同**的变体只能新增，新旧两条靠流体不同天然区分，旧产线不受影响。
- **只有副产不同**的变体，两条输入完全一样，后加的那条永远选不中——只能直接替换。代价是燃料基的两条工业氢氟酸版本消失。

## 已知限制

- 目标配方钉在 GT5U 5.09.54.265。GT++ 升级后若某条配方变了，日志会打一行「未命中」，那条改动被跳过，**原配方原样保留、游戏照常加载**——不会崩，也不会删错。
- 极少数例外：一次改动覆盖两张配方表（B 组的「氢氧化锂 → 氟化锂」）、或某个方块有两种形式（反应堆护盾、处理厂外壳）时，若后一半失败，前一半可能已经生效，而日志仍记「未命中」。这是 1.0.0 的已知缺口，见 AGENTS.md。
- 只在开发回路（66 个模组）验证过，没有在完整的 243 模组包里跑过。
- 不改多方块结构，结构方块的种类与数量与原来一致。
