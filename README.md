# LFTR: Price Drop

GT++ 的 LFTR 造价高，燃料线绕不开工业氢氟酸，处理也慢。这个模组在游戏加载完之后改掉其中一批配方：外壳和主机换成主线材料，燃料线多一条不用工业氢氟酸的走法，燃料和乏燃料处理快一倍。

可选。装了才生效，不装什么都不变。

> ⚠️ **不符合星门（Stargate）规则。** 星门身份要求在不改平衡的前提下达成，而本模组有意改动造价与处理速度。跑星门、或准备申请星门身份时不要安装。
>
> 与 GTNH 官方、GT++、GT5U 均无隶属关系。jar 里不含上游的任何代码或资源，只在运行期调用它们的配方 API。

## 安装

GTNH 2.9.0（当前 rc2），Minecraft 1.7.10，需要 GT5-Unofficial 5.09.54.265。

把 `lftrpricedrop-1.0.0.jar` 放进 `mods/`。

### 氢氟酸，6 条

三条加新配方，三条把原配方换掉。换算沿用 GT++ 的比例：1 mB 工业氢氟酸 = 2 mB 普通氢氟酸。

| 配方 | 怎么处理 | 变化 |
|---|---|---|
| 碳酸锂 → 氟化锂（化学浸洗机） | 新增 | 工业氢氟酸 500 → 普通氢氟酸 1000 |
| 氢氧化锂 → 氟化锂（化学反应釜、大型化学反应釜） | 新增 | 工业 500 → 普通 1000 |
| U-233 + U-235 → 四氟化铀（混合机） | 新增 | 工业 10000 → 普通 20000 |
| 四氟铍酸铵 → 氟化铍（大型化学反应釜） | 替换 | 副产工业 1000 → 普通 2000 |
| 燃料基（工业高炉） | 替换 | 输入 +2 空单元；副产 2 个工业氢氟酸单元 → 4 个普通氢氟酸单元 |
| 燃料基（化工厂） | 替换 | 副产工业 2000 → 普通 4000 |

## 配置

`config/lftrpricedrop.cfg` 里只有一项，改 `false` 就全部关掉，配方一条不碰。

```
B:enablePriceDrop=true
```
